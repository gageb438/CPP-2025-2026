Sample API Reference

Base URL: https://api.example.com

Input

  • id (integer, required) – Unique user ID

Processing

The server validates the ID, queries the database for a matching user record, and formats the result into JSON. If the user does not exist, an error is returned.

Output

{
    "id": 1,
    "name": "John Doe",
    "email": "john@example.com"
}
